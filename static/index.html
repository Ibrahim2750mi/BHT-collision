Number size (bits)

Bits = how big the numbers are. 4 bits means 16 possible numbers, 8 bits 256, 16 bits 65,536. Bigger means harder to search, and the quantum advantage grows.

[Words used here] Scrambler = hash function (same thing, two names): a fixed recipe that turns a number into a shorter number. Fingerprint = hash = digest: what comes out. Twin / collision: two different numbers whose fingerprints are equal. Your password is first turned into a number x; the scrambler then turns x into a fingerprint. x and its fingerprint are an input and an output, not a pair. After each step the page waits for you: click the black button at the bottom of the screen to continue. Each step is its own slide: swipe left for the next step, swipe right to go back (or use the arrows, tabs, or arrow keys).
